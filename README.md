# Meow Core

> Meow 的 HarmonyOS 音乐播放器功能框架 / 参考实现。
>
> 本仓库并不是正式版应用的完整源码，也不以长期同步正式版 UI、动效和全部产品细节为目标。

## 项目定位

Meow Core 主要公开播放器的基础架构、协议接入和常用功能实现，方便学习、参考、二次开发或自行设计新的界面。

仓库中的 UI 只承担“功能可操作、逻辑可验证”的作用，保持简单可用。正式版中的视觉设计、复杂动效、品牌化交互以及部分实验性实现不会同步到这里。

这不是一个全职维护的开源项目。项目以个人开发为主，更新节奏取决于时间和实际需求：

- 不承诺固定更新周期或 Roadmap
- 不保证 Issue 一定回复或修复
- 不保证 PR 一定合并
- 不提供一对一部署、服务器或环境配置支持
- Core 与正式版允许存在版本差异，不保证始终完全同步

如果某个功能对你很重要，欢迎基于现有框架自行实现或维护自己的分支。

## 当前功能

目前已包含的主要功能包括：

- Navidrome / Subsonic 音乐源
- WebDAV / OpenList / AList 兼容 WebDAV 音乐源
- 音源测试、添加、编辑、删除，以及 NAS / WebDAV / 合并模式
- 首页、歌曲、专辑、歌手、歌单、收藏、最近播放
- 搜索、搜索建议和本地搜索历史
- AVPlayer 播放、暂停、Seek、上一首 / 下一首、播放队列
- 顺序、单曲循环、列表循环、随机播放
- 歌词加载与歌词跳转
- 音质切换、ReplayGain、音频焦点等播放相关设置
- 收藏本地缓存和待同步队列
- 远程 / 本地歌单缓存和离线元数据
- 新建、重命名、删除歌单，以及歌曲加入歌单
- 歌单分享码和导入码基础流程
- 本地音乐导入与扫描
- Navidrome 歌曲下载及下载管理
- 网络电台
- 关注歌手及基础推荐权重逻辑
- 听歌统计
- 睡眠定时
- 歌曲分享 / 复制信息
- 音频、图片、元数据缓存管理
- 数据加载数量限制
- 基础主题、字号和界面相关设置
- HarmonyOS 媒体会话、后台播放等核心逻辑

以上列表用于说明当前框架覆盖范围，并不代表所有边缘场景都已经经过完整测试。

## 不包含的内容

本仓库不会提供正式版完整视觉实现，例如：

- 正式版 HDS Navigation 表现层
- 正式版 mini player / miniBar
- 唱片、音浪、Orb 等视觉效果
- 高级转场和一镜到底动画
- 正式版渐变、模糊、动态背景和细节调参
- 节日 / 特供图标和部分品牌资源
- 正式版布局微调和品牌化交互细节

简单来说：**功能框架可以参考和继续开发，UI 和动效请自行设计。**

## 当前状态

当前版本已经可以作为一个可运行的功能框架使用，核心流程基本齐全。

仍可能存在特定服务器、编码格式、系统版本或边缘操作下的兼容性问题。例如 Navidrome 的 192k / 128k 实时降码率需要服务器端 FFmpeg / 转码配置正常；服务器转码失败并不一定是客户端播放器问题。

后续更新不会要求 README 每次同步大量细节。功能修复和新增内容可以主要记录在 GitHub Releases / CHANGELOG 中。

## 更新方式

- **CHANGELOG**：记录新增、修复、调整和已知问题
